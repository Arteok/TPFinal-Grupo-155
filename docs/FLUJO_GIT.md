# Flujo de trabajo con Git

Para el desarrollo del proyecto se utilizará Git y GitHub como sistema de control de versiones.

La rama `main` contendrá la versión estable del proyecto.

Las modificaciones se realizarán en ramas independientes según la tarea o funcionalidad a desarrollar. Se utilizarán nombres descriptivos, por ejemplo:

- `docs/segunda-entrega`
- `feature/agenda`
- `feature/turnos`
- `feature/servicios`
- `feature/pacientes`
- `fix/nombre-correccion`

Cada cambio será registrado mediante commits claros y descriptivos.

Una vez finalizado el trabajo de una rama, los cambios serán integrados nuevamente en `main`. Cuando trabajen ambos integrantes, se utilizarán Pull Requests para permitir la revisión antes de realizar el merge.
