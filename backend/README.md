# Backend

API REST del Sistema de Gestión de Turnos, en Java con Spring Boot y Gradle.

La organización en capas —controller, service, repository, domain— está definida en [`docs/ARQUITECTURA.md`](../docs/ARQUITECTURA.md). El esquema de la base de datos que consume esta API está en [`database/schema.sql`](../database/schema.sql).

El código se agrega después de la aprobación del alcance por parte del tutor y del comité.
