# Frontend

Interfaz web del Sistema de Gestión de Turnos, en React con TypeScript y Vite.

Se comunica con el backend únicamente por API REST, según lo definido en [`docs/ARQUITECTURA.md`](../docs/ARQUITECTURA.md). Incluye el panel de la profesional y el flujo público de reserva de turnos.

El código se agrega después de la aprobación del alcance por parte del tutor y del comité.
